Other Mac install options

Homebrew

Use this for terminal-first workflows and reproducible setup.

  1. Tap the Tiny Clips cask:
    brew tap jamesmontemagno/tiny-clips https://github.com/jamesmontemagno/tiny-clips
  2. Trust the tap if Homebrew requires it:
    brew trust jamesmontemagno/tiny-clips 2>/dev/null || true
  3. Install Tiny Clips:
    brew install --cask tiny-clips

A tiny capture loop: grab, polish, share.

Tiny Clips stays out of the way until you need it, then gives screenshots, videos, and GIFs the few tools they need before leaving your desktop.

Capture anything

Select a region and save a PNG screenshot, MP4 recording, or animated GIF without opening a heavyweight suite.

  • Region capture for screenshots, video, and GIFs
  • 24/30/60 fps recording with optional audio
  • Menu bar on Mac, system tray on Windows

Polish before sharing

Clean up the clip before it leaves your machine: trim motion, style screenshots, add context, and redact what should stay private.

  • Video and GIF trimming before export
  • Backgrounds, padding, shadows, annotations, and redactions
  • Webcam overlays with shape, corner, and size controls

Find it later

On Mac, Clips Manager keeps every screenshot, video, and GIF organized without a paid unlock.

  • Search, tags, notes, collections, and favorites
  • Batch actions for organizing multiple clips
  • Uploadcare sharing links when you need to send a clip
Workflow settings for power users
  • Save destinations: Use sensible defaults or choose a custom folder.
  • Clipboard flow: Copy captures automatically after save.
  • Finder/Explorer handoff: Reveal files immediately when export finishes.
  • Format controls: Tune screenshot quality, video frame rate, GIF width, and countdown behavior.
